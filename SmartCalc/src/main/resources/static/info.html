Welcome to the documentation for SmartCalc v3.0!

About the Project

SmartCalc v3.0 is a versatile calculator application developed in Java 8 language. The calculator provides the capability to perform various arithmetic operations, compute mathematical functions, as well as handle credits and deposits.

Key Features

Implementation of SmartCalc v3.0

  • Implemented in C11 language using GCC compiler.
  • Ability to utilize additional QT libraries and modules.
  • Program built using Makefile with targets: all, install, uninstall, clean, dvi, dist, test, gcov_report.

Simple Calc Tab

Simple interface for inputting mathematical expressions including functions like cos(x), sin(x), tan(x), acos(x), asin(x), atan(x), sqrt(x), ln(x), log(x).

Credit Calc Tab (Extra)

"Credit calculator" mode with the ability to calculate monthly payments, overpayment on credit, and total payments.

Deposit Calc Tab (Extra)

"Deposit profitability calculator" mode with the ability to calculate accrued interest, tax amount, and final balance by the end of the term.
